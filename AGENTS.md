# AGENTS.md — орієнтир для бізнес-аналітика

## Про проєкт

Це навчальна копія веб-сайту **Фонду ім. Бориса Лятошинського** у рамках курсу **«Spec Driven Development with AI»**: учасники формулюють вимоги й специфікації, а потім змінюють існуючий **Next.js**-застосунок (двомовний `uk` / `en`) разом із AI-інструментами. Для БА головне — зрозуміти, які сторінки та сценарії обслуговує сайт, як дані проходять від інтерфейсу через сервіси до «бази», і як фіксувати домовленості в `docs/` та у власних специфікаціях курсу. Детальніше про запуск і папки — у [README.md](README.md); процеси гілок і PR — у [docs/](docs/).

## Основні сторінки (маршрути під `/{lang}/…`, `lang`: `uk` | `en`)

| Маршрут | Бізнес-призначення |
|--------|---------------------|
| `/` | Головна: презентація фонду, ключові блоки (біографія, творчість, співпраця, новини, події), вхід у глибші розділи. |
| `/about-us` | Про фонд: місія, цілі, засновники, напрями діяльності, довіра до організації. |
| `/biography` | OoPs ЩоСь піШлО нЕ ТаК |
| `/artistry` | Творчість і спадщина: твори, образ митця для дослідників і широкої аудиторії. Ой! ПоРожНьО |
| `/archive` | АрХів |
| `/archive/{fund}` | ні |
| `/archive/{fund}/{case}` | ні |
| `/news` | Новини та оголошення фонду (актуальність, комунікації). |
| `/research` | Ой! ПоРожНьО |
| `/cooperation` | Партнерство: умови та заклики до співпраці з інституціями. |
| `/support-us` | Підтримка фонду (донати, волонтерство, інші канали допомоги). |
| `/contacts` | Контакти та звернення до фонду (у т. ч. форма звернення через API). |
| `/war-in-ukraine` | Позиція та діяльність фонду в контексті повномасштабної війни. |
| `/privacy-policy`, `/terms` | Юридичні сторінки (політика конфіденційності, умови користування). |

Шляхи до логіки й даних: сторінки — `app/[lang]/`, API — `app/api/`, бізнес-правила — `app/services/`, доступ до даних — `app/infrastructure/`, тексти UI — `i18n/messages/`.

## Конвенції для команди

| Тема | Домовленість |
|------|----------------|
| Мова коду | **TypeScript** у всьому застосунку; типи для DTO, сервісів і пропсів компонентів. |
| Експорти | У **новому** коді — **іменовані експорти** (`export function …`, `export const …`); уникайте `export default`, окрім вимог **Next.js App Router** (файли `page.tsx`, `layout.tsx`, `middleware.ts` тощо). |
| Мова продукту | **Українська (`uk`) — основна**: `defaultLocale: 'uk'` у `i18n/routing.ts`; переклади додавайте насамперед у `uk`, потім у `en`. Специфікації та BA-документи в `docs/` — українською. |
| Іменування файлів | Компоненти — PascalCase; папки та утиліти — kebab-case ([file-naming-conventions.md](docs/file-naming-conventions.md)). |
| Тести | Поруч із кодом, `*.test.ts(x)`; перед PR — `npm test`. |
| Git | Conventional Commits, гілки й PR — [docs/gitflow.md](docs/gitflow.md), [docs/pull-request-workflow-guidelines.md](docs/pull-request-workflow-guidelines.md). |

Для BA-документації фіч можна використовувати агента `.cursor/agents/ba-docs.md` і шаблони з `course/`.

## Навчальне середовище і дані

Репозиторій — **шаблон курсу**, а не бойовий продакшен Фонду. Зовнішня MongoDB не потрібна: при `npm run dev` піднімається **MongoDB в пам’яті**, скрипт `scripts/seed-memory-mongo.js` наповнює її **демо-даними**. **База повністю скидається при кожному перезапускі** застосунку — не покладайтеся на збереження змін між сесіями й не трактуйте seed як «джерело правди» для реального архіву; для приймання описуйте очікувану поведінку й дані в специфікації, а не стан після вашого локального тесту вчора.
