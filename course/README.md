# Матеріали курсу

Допоміжні документи для вправ курсу «Spec Driven Development with AI». Покрокові інструкції по днях ви знайдете на навчальній платформі.

| Файл | Що це | Коли потрібен |
|---|---|---|
| `installation-guide.md` | Встановлення Git, Node.js і Cursor (Windows, macOS, Linux) | До дня 1 |
| `cursor-model-tips.md` | Як вибрати найдешевшу модель Cursor й заощадити ліміт | День 1 |
| `figma-mcp-setup.md` | Підключення Figma MCP до Cursor, ліміти Figma | День 4 (і підготовка до дня 3) |
| `templates/` | Шаблони специфікацій і PoC-зрізу, промпти | День 4 |

Шаблони копіюйте в папку `docs/` вашого репозиторію й заповнюйте там.
