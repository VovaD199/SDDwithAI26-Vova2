# Підсумок PoC: контакти, «Про фонд», підтримка (13 листопада 2026)

Документ для стейкхолдерів. Описує навчальну пісочницю сайту Фонду, а не бойовий продакшен.

---

## 1. Гіпотеза: яке питання ми тестували

Ми перевіряли **три окремі ідеї** в одній робочій сесії:

1. **Контактна форма** — чи зручніше для користувача дозволити **коротші повідомлення** (мінімум **5** символів замість 10).
2. **Сторінка підтримки (англійська)** — чи **краще звучить** заклик **«Become a patron»** замість попередніх формулювань про підтримку фонду на кнопках.
3. **Сторінка «Про фонд»** — як виглядає сайт, якщо в демо-даних **прибрати текст місії** (залишити блок технічно, але без змісту), щоб оцінити порожній або «скелетний» варіант секції.

Це **гіпотези для демо**, а не рішення «так і йдемо в прод».

---

## 2. Налаштування пісочниці

- **Гілка:** локальна **sandbox-гілка** (навчальна копія репозиторію курсу).
- **Дані сторінок:** при кожному запуску локального сервера використовується **тимчасова база в пам’яті**; її наповнює скрипт **`scripts/seed-memory-mongo.js`**. Зміни в seed **застосовуються після перезапуску** сервера розробки — між сесіями дані **не зберігаються**, якщо їх не зафіксувати в коді.
- **Контроль контенту «Про фонд»:** саме в цьому seed-файлі спорожнили блок **OurMission** для сторінки **about-us**.
- **Форма та підписи кнопок:** зміни в **коді валідації**, **перекладах** (українська та англійська для текстів помилок; англійська для нових підписів кнопок) і **документації** — без зовнішньої бази даних.

---

## 3. Зроблені зміни (кожна — одне речення)

1. **Мінімальна довжина повідомлення** у контактній формі зменшена з **10 до 5** символів на екрані і на сервері при відправці.
2. **Тексти помилок** українською та англійською оновлені, щоб говорити про **5** символів, а не 10.
3. На **англійській** версії кнопка донату в **підвалі** і **головна кнопка** на сторінці підтримки тепер підписані **«Become a patron»**.
4. У **демо-даних** сторінки «Про фонд» секція **місії** залишилась у структурі сторінки, але **без текстів пунктів** і з **порожнім заголовком** (зображення в блоці лишились).
5. Оновлено **опис фічі контактної форми** в документації та **автоматичні перевірки** в коді під новий мінімум повідомлення.

---

## 4. Докази: що спостерігали

| Тип доказу | Що є на руках |
|------------|----------------|
| **Поведінка в застосунку (браузер)** | У цій сесії **не було** повного проходження сторінок очима в браузері після усіх змін; **потрібен** короткий перегляд після перезапуску сервера (див. розділ 6). |
| **Автоматичні перевірки** | Раніше в сесії успішно проходили перевірки, пов’язані з **контактною формою** та **серверною валідацією полів** (окремі тести в коді) — лише для зміни мінімуму повідомлення. |
| **Зміни в коді (diff)** | Змінено **дев’ять файлів** у гілці: константи валідації, форма контактів, переклади, seed, документація, тести (орієнтовно **кількадесят рядків** загалом — без окремого збереженого скріншота статистики в цьому документі). |
| **Скріншоти** | **Немає** — за потреби додати після ручної перевірки: about-us, contacts, support-us (en). |

## 5. Чекліст валідації

### A. Спорожнена місія на «Про фонд» (seed)

| | |
|---|---|
| **Доведено** | Зміна записана в **seed-файлі** в репозиторії. |
| **Не доведено** | Як сторінка **виглядає** для відвідувача; чи немає помилок; чи зображення лишились. |
| **Потребує розробника / дизайну** | Чи прийнятно показувати **порожню** місію на демо; чи це окремий експеримент, чи помилка контенту. |

### B. Контактна форма — мінімум 5 символів

| | |
|---|---|
| **Доведено** | Логіка змінена в коді; **частина** автоматичних перевірок у проєкті проходила для цієї зміни. |
| **Не доведено** | У браузері: успішна відправка з **5** символами та відмова з **4**; сторінки **контактів** і **співпраці**; **українська та англійська** мови; відповідь **сервера** при короткому повідомленні. |
| **Потребує розробника / продукту** | Чи **5 символів** — рішення для реального сайту; узгодження з **завданням №2** (телефон, файл), якщо там ще зафіксовано **10**; чи не буде занадто багато **дуже коротких** звернень. |

### C. Підпис «Become a patron» (лише англійська)

| | |
|---|---|
| **Доведено** | Тексти **оновлено** в файлі англійських перекладів для **футера** та **кнопки на сторінці підтримки**. |
| **Не доведено** | Вигляд на **`/en/support-us`** і в **футері** на інших англійських сторінках; **українська** лишилась по-старому — чи це навмисно. |
| **Потребує маркетингу / продукту** | Затвердження формулювання **patron**; чи змінювати **українську**; чи зміна **всього футера англійською** входить у план. |

### D. Загалом по гілці

| | |
|---|---|
| **Доведено** | Три різні експерименти **змішані в одному наборі змін** — видно в diff. |
| **Не доведено** | Повний прогін **усіх** автоматичних перевірок проєкту після останніх змін. |
| **Потребує розробника** | **Розділити** зміни на окремі завдання перед злиттям; переконатися, що **перевірки на сервері** зелені. |

## 6. Рекомендований наступний крок

Перезапустити локальний сайт, **15–20 хвилин** пройти вручну чотири точки (**«Про фонд»**, **контакти**, **співпраця**, **support-us англійською**) з короткими нотатками й **2–3 скріншотами**, після чого стейкхолдери вирішують: **прийняти**, **відкотити** або **винести кожну ідею в окреме завдання** — і не зливати в прод без цього кроку.
